# API

Interactive OpenAPI documentation is at `/docs` when the API is running. All business endpoints are versioned beneath `/api/v1`, JWT-protected after demo login, and return calculated synthetic-demo data scoped to the authenticated user.

Key routes: auth login/me; dashboard summary; transactions/list/detail/category correction; analytics spending/cashflow/merchants/recurring/comparison; coach chat/run-out/insights; budgets current/recommendation/create/update; goals list/create/detail/plan; forecast; financial health; alerts; weekly/monthly reports; learning; offers; health/status.
